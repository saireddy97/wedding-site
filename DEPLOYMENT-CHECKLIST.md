# Launch checklist

- [ ] Replace placeholder names in `src/data/site.json`.
- [ ] Add the confirmed wedding date in ISO format (`YYYY-MM-DD`).
- [ ] Update each event's date, time, venue, dress code, and map URL.
- [ ] Replace sample gallery images with approved photos.
- [ ] Check all text and spelling on a mobile screen.
- [ ] Confirm no private family information is committed to the public repository.
- [ ] Create a GitLab project and push to the default branch.
- [ ] Confirm the GitLab Pages pipeline succeeds.
- [ ] Verify the Pages URL, navigation, images, and WhatsApp share links.
- [ ] Add a custom domain later if desired; configure `SITE_BASE_PATH=/` for it.
- [ ] Verify DNS and enable HTTPS.
